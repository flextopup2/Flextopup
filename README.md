# Flextopup

React + Vite + TypeScript application for wallet funding with Supabase and Paystack.

## Setup

1. Install dependencies with `npm install`.
2. Copy `.env.example` to `.env.local` and set your Supabase project URL and publishable key.
3. Run `npm run dev`.

Never put Supabase service-role keys or Paystack secret keys in browser code. See `supabase/README.md` for backend setup.
